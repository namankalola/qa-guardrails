# Controls matrix (audit evidence)

Maps each guardrail to OWASP ASVS 4.0.3, SOC 2 (2017 TSC), ISO/IEC 27001:2022 Annex A and
SLSA v1.0. **Evidence** is where an auditor finds proof the control ran. Mappings are a
starting point for the GRC team to confirm. They are not a certification claim.
